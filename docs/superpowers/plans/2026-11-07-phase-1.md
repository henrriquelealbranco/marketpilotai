# Fase 1 — plano de implementação

**Goal:** entregar a fundação executável do MarketPilot AI solicitada no prompt.
**Architecture:** monorepo com Next.js, Fastify, contratos compartilhados e PostgreSQL/Prisma. Separação explícita entre conta autenticada e demonstração.
**Tech Stack:** TypeScript, React, Tailwind, primitives shadcn/ui, Recharts, TanStack Query/Table, Framer Motion, Prisma e PostgreSQL.

## Restrições

Somente Fase 1. Interface pt-BR. Nenhuma operação externa ou deploy. Nenhum número simulado apresentado como resultado real. Sem segredos versionados. Execução neste chat, seguindo a autorização de implementação do pedido.

## Entregas

- [x] Fundação: manifests, lint, TypeScript e contratos Zod. Arquivos em package.json, apps/* e packages/contracts. Testes de filtros, valores monetários e isolamento de dados em tests/unit/dashboard.test.ts.
- [x] Identidade persistente: packages/database/prisma/schema.prisma e migrations; apps/api/src/auth.ts e app.ts. Testes unitários de hash e sessão, seguidos da implementação. Integração: cadastro cria workspace, login rejeita senha errada, cookie não expõe senha, sessão expira, logout revoga, leitor não modifica preferências, CSRF rejeita origem externa e duas contas não compartilham dados.
- [x] Experiência: apps/web/src/components para primitives, shell e dashboard; app/demo, app/app e app/login. Identidade oficial roxa/lilás, tipografia Inter, contraste, foco e reduced-motion. Usar os contratos da API e TanStack Query. E2E: filtros mudam dados, tema claro, navegação por teclado e mobile sem overflow.
- [x] Preparação das áreas: navegação real com páginas que informam fase e integração pendente; integrações não conectadas. Nenhum botão simula publicação.
- [x] Verificação e documentação: lint, unitários, integração, typecheck, build e E2E. README com comandos e limitações; docs/phase-1.md com estado de cada entrega e preparação da Fase 2. CI reproduz os comandos com PostgreSQL isolado.
